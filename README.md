### 02 &nbsp;/&nbsp; Work

**[LSTM Research Inspector](https://github.com/GodWar9/lstm_stock_prediction)** &nbsp;·&nbsp; [live](https://lstm-research.vercel.app)
A research platform for leakage-safe time-series model evaluation. Rust handles data, ONNX inference, backtesting and Monte Carlo simulation; Python is used only for training. Datasets and models are hashed, and a model is published only after PyTorch, ONNX Runtime and tract agree.
<sub>Rust · PyTorch · ONNX · React</sub>

**[Finacle](https://github.com/GodWar9/Finacle)**
A double-entry core-banking engine. Balance is enforced in the database, every write is idempotent, events leave through a transactional outbox, and a C++ engine reconciles settlement files three ways, surfacing every mismatch as an exception.
<sub>Rust · C++ · FastAPI · Kafka · PostgreSQL</sub>

**[Zex](https://github.com/GodWar9/zex-cli_1)**
A terminal coding assistant that trims repeated context, spreads requests across model providers, and scans proposed file changes before they are written.
<sub>TypeScript · React/Ink · Node</sub>
